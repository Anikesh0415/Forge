### B. Requirements Verification & Static Analysis

1. **Thread Safety (JSONL File Locks & Concurrency)**:
   - `SafetyLogger` instantiates `self._lock = threading.Lock()`.
   - File writes in `log_shadow_record` (`src/safety_logger.py:190-192`) and `log_safety_audit` (`src/safety_logger.py:211-213`) use `with self._lock:` block wrapping open/write calls.
   - `reload_rules()` also protects `self.rules` update with `with self._lock:`.
   - *Observation*: `check_boundary_violation()` reads `self.rules` without acquire lock. While `dict` references in Python are GIL-atomic, dynamically updating `self.rules` via `reload_rules` during concurrent checks could read an in-flight dictionary replacement. However, standard write locks for JSONL appending prevent inter-thread file corruption.

2. **Boundary Coordinate Math (Bounding Box Checks)**:
   - Evaluates dict-style rules (`x_min`, `y_min`, `x_max`, `y_max`) and array-style rules (`bounds: [x_min, y_min, x_max, y_max]` or direct array `[x_min, y_min, x_max, y_max]`).
   - Boundary test math at `src/safety_logger.py:153`: `float(x_min) <= x_val <= float(x_max) and float(y_min) <= y_val <= float(y_max)`.
   - Correctly includes bounding edges (`<=`). Handles floating point inputs.

3. **Error Handling for Missing/Malformed Payloads**:
   - `check_boundary_violation` checks `isinstance(action_payload, dict)` returning `False` if not a dict (`src/safety_logger.py:56-57`).
   - Safe parsing of target text with fallbacks: `action_payload.get("target") or action_payload.get("text") or action_payload.get("command") ... or ""`.
   - Coordinate extraction attempts `x`/`y`, `target_x`/`target_y`, and `point` (tuple/list or dict).
   - Non-numeric coordinate values wrapped in `try ... except (ValueError, TypeError): pass` (`src/safety_logger.py:167-168`), avoiding unhandled exceptions.

4. **Screenshot ROI Crop Bounds**:
   - `crop_target_element` in `src/agent_loop.py:70-73` clamps ROI boundaries using `max(0, ...)` and `min(img_w / img_h, ...)`:
     ```python
     left = max(0, int(x - half_w))
     upper = max(0, int(y - half_h))
     right = min(img_w, int(x + half_w))
     lower = min(img_h, int(y + half_h))
     ```
   - *Observation*: If target $(x, y)$ lies outside image size (e.g. negative or $x > img\_w$), `left` or `upper` could equal `right` or `lower`, or `left` could be greater than `right` if $x < -half\_w$. In PIL, `crop((left, upper, right, lower))` with `left >= right` creates a 0-width image or box inversion.

5. **Context Buffer Integrity**:
   - `ActionBuffer` in `src/memory_buffer.py` uses `collections.deque(maxlen=5)`.
   - `get_history()` exposes snapshot as `list(self.buffer)`.
   - `detect_loop()` evaluates last 3 items for identical action+target signatures.
   - Preserves state across agent iterations without memory leaks.

## 3. Caveats & Adversarial Findings

### Findings List

1. **[Minor] Potential Box Inversion in `crop_target_element` for Negative Coordinates**:
   - *Location*: `src/agent_loop.py:70-73`
   - *Detail*: If $x < -100$ or $y < -100$ (far off-screen user click payload), `int(x + half_w)` can be negative, resulting in `left = 0` and `right = -10`, which triggers an unhandled PIL cropping error or empty crop.
   - *Mitigation*: Ensure `right = max(left, min(img_w, int(x + half_w)))` and `lower = max(upper, min(img_h, int(y + half_h)))`.

2. **[Minor] Bi-directional Substring Search in Restricted App Matching**:
   - *Location*: `src/safety_logger.py:101`
   - *Detail*: Code evaluates `app_lower in app_name.lower() or app_name.lower() in app_lower`. If a rule specifies `cmd.exe`, and action target is `c`, `app_name.lower() in app_lower` evaluates `True` ('c' in 'cmd.exe'), blocking legitimate apps with short names.
   - *Mitigation*: Restrict substring check to `app_lower in app_name.lower()`.

3. **[Minor] Inconsistent Spatial Coordinate Extraction in `handle_interactive_override`**:
   - *Location*: `src/agent_loop.py:116-117`
   - *Detail*: `handle_interactive_override` only inspects `user_action.get("x")` and `user_action.get("y")`, omitting support for `point` arrays or `target_x`/`target_y` supported in `SafetyLogger`.
   - *Mitigation*: Use standard coordinate extraction helper across both modules.

4. **[Minor] Unlocked Rule Reading in `check_boundary_violation`**:
   - *Location*: `src/safety_logger.py:70, 96, 135`
   - *Detail*: `self.rules` dictionary is accessed during `check_boundary_violation` without holding `self._lock`. If `reload_rules` mutates `self.rules` concurrently, a thread race condition could occur.
   - *Mitigation*: Copy or read `self.rules` under `self._lock`.

5. **[Minor] Non-blocking Headless Screenshot Fallback in Test Execution**:
   - *Location*: `tests/test_safety_logger.py:186-190`
   - *Detail*: `test_agent_loop_safety_enforcement` passes cleanly, but logs screenshot fallback warnings when executed on headless test setups.
   - *Mitigation*: Safe fallback functions as designed.
